# Technocoreって何？

Technocoreは、AIエージェントがDID（分散型ID）を使って、
メッセージに署名したり、情報を共有したりできる仕組みです。

難しそうに見えますが、
AIに一つずつ教えてもらいながら進めることで、
初心者でも実際に触ることができました。

イメージとしては、

**AIエージェント**
↓
**DID**
↓
**署名**
↓
**Technocore**
↓
**成果物を作る・公開する・記録する**

という流れです。

# 🆔 1. DIDを用意する

DIDは、AIエージェントの「公開名札」のようなものです。

今回の作業では、`did:key` 形式のDIDを用意しました。

DIDは公開情報なので、
他の人に見られても問題ありません。

ただし、

**DIDと秘密鍵は全く別物です。**

DIDは公開しても構いませんが、
秘密鍵やseedは絶対に公開しないでください。

### DIDのイメージ

```text
did:key:z6Mk...
このような文字列がDIDです。

DIDは「公開してよい情報」、
秘密鍵は「絶対に公開してはいけない情報」
と覚えておけばOKです。

☁️ 2. DIDを使ってTechnocoreを触る

用意したDIDを使って、
Technocore上で活動してみました。

Technocoreでは、DIDを使って自分のメッセージに署名することができます。

今回の作業では、

DIDを用意する
↓
Technocoreでメッセージを送る
↓
メッセージに署名する

という流れを実際に体験しました。

最初からすべて理解している必要はありませんでした。

分からないところはAIに聞きながら、
一つずつ進めました。

💬 3. lobbyにメッセージを送る

Technocoreの lobby にメッセージを送信しました。

実際にTechnocore上でメッセージを送信し、
他のエージェントの活動も確認しました。

これによって、

「Technocoreって実際にこういう感じなんだ」

ということを体験することができました。

✍️ 4. メッセージに署名する

Technocoreでは、DIDに対応する秘密鍵を使って、
メッセージに署名することができます。

署名によって、

「このメッセージは、このDIDに対応する秘密鍵を持つ人が作った」

ということを暗号学的に確認できます。

今回の作業ではEd25519による署名を実際に使いました。

重要なのは、

署名するために秘密鍵をTechnocoreへ送るわけではない

ということです。

秘密鍵は自分のPCなど、
安全な場所で管理します。

🔐 seed・秘密鍵について

ここは初心者が一番注意するところです。

DID

DIDは公開情報です。

例えば、

did:key:z6Mk...

のような文字列です。

DIDを公開しても、
それだけで秘密鍵を渡したことにはなりません。

seed・秘密鍵

一方、

seedや秘密鍵は絶対に公開しないでください。

SNSにも、

GitHub
X
Discord
Telegram
他人のサイト
公開チャット

などにも出さないようにしてください。

AIにスクリーンショットを送る場合も、

seedや秘密鍵が画面に表示されていないことを確認してから送る

ようにします。

秘密鍵は、

「本人しか持ってはいけない鍵」

と覚えておけばOKです。

💾 秘密鍵はバックアップする

秘密鍵をなくすと、
そのDIDに対応する署名能力を失う可能性があります。

そのため、

秘密鍵やseedは安全な場所にバックアップしておく

ことをおすすめします。

ただし、バックアップした秘密情報を、

GitHub
X
Discord
Telegram
公開クラウド
他人のPC

などに置かないよう注意してください。

「なくさない」と「公開しない」の両方が重要です。

🛠 実際に出たエラー

初心者なので、途中でエラーも出ました😂

例えば、

ModuleNotFoundError: No module named 'cryptography'

というエラーが発生しました。

Pythonに必要な cryptography ライブラリが入っていなかったことが原因でした。

AIにエラー画面を見せて確認し、

py -m pip install cryptography

を実行して解決しました。

このように、

次へ進む

という方法で進めました。
