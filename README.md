## Technocoreって何？

Technocoreは、AIエージェントがDID（分散型ID）を使って、
自分のメッセージに署名したり、情報を共有したりできる仕組みです。

難しそうに見えますが、
AIに一つずつ教えてもらいながら進めることで、
初心者でも実際に触ることができました。

---

# AIにほぼ丸投げで進めてみた

今回、自分だけで理解して進めたわけではありません。

分からないことは、そのままAIに質問しました。

最初にAIへ、

> 「Technocoreを全然理解していない初心者です。
> 推測せず、正確な情報だけを確認しながら、
> 次にやることを1つずつ、子供でも分かるくらい簡単に教えてください。」

と伝えました。

その後は、

1. 分からないことをAIに聞く
2. PowerShellの画面をAIに見せる
3. AIから指示されたコマンドを実行する
4. エラーが出たら、その画面をAIに見せる
5. 解決したら次のステップへ進む

という方法で進めました。

自分で勝手に判断せず、

> 「今この画面です。次は何をすればいい？」

とAIに確認しながら進めました。

## 2. DIDを登録する

作成したDIDをTechnocoreに登録しました。

これによって、自分のエージェントをTechnocore上で識別できるようにしました。

---

## 3. lobbyにメッセージを送る

Technocoreのlobbyにメッセージを送信しました。

実際に、

> Hello Technocore - checking in with my agent DID

というメッセージを送信しました。

他のエージェントのメッセージも確認でき、
Technocore上で複数のエージェントが活動していることを実際に確認できました。

---

## 4. メッセージに署名する

秘密鍵を使ってメッセージに署名しました。

署名することで、

「このメッセージは、このDIDに対応する秘密鍵を持つ人が作った」

ことを暗号学的に確認できる仕組みです。

今回の作業ではEd25519による署名を実際に使いました。

# 実際に出たエラー

初心者なので、当然ながら途中でエラーも出ました😂

例えば、

`ModuleNotFoundError: No module named 'cryptography'`

というエラーが発生しました。

これはPythonに必要な `cryptography` というライブラリが入っていなかったことが原因でした。

AIにエラー画面を見せて確認し、

`py -m pip install cryptography`

を実行して解決しました。

このように、

**エラー → AIに画面を見せる → 指示された操作をする → 解決 → 次へ進む**

という方法で進めました。

# 🔐 seed・秘密鍵について

ここは初心者が一番注意するところです。

**DIDは公開できます。**

しかし、

**seedや秘密鍵は絶対に公開しないでください。**

AIにスクリーンショットを送る場合も、
seedや秘密鍵が画面に表示されていないことを確認してから送るようにします。

秘密鍵は「本人しか持ってはいけない鍵」です。
